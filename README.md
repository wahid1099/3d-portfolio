# Md. Wahid: 3D Quantum-Safe Portfolio

React + TypeScript + Vite + Three.js (React Three Fiber) + Framer Motion + Tailwind CSS.

## Run locally
```bash
npm install
npm run dev
```
Open http://localhost:5173

## Build for production
```bash
npm run build     # outputs to dist/
npm run preview
```

## Deploy (Netlify)
Build command: `npm run build` · Publish directory: `dist`

## Edit your content
All text lives in `src/data/` (profile.ts, projects.ts, tech.ts, pipeline.ts).
